# Helper icons

Place one SVG icon here for each repository in the helper navigation.

Expected filenames:

- `canic.svg`
- `icydb.svg`
- `ic-timers.svg`
- `ic-memory.svg`
- `ic-query.svg`
- `ic-backup.svg`
- `ic-blob-storage.svg`
- `ic-testkit.svg`
- `ic-delegated-auth.svg`

Icons should:

- use a square `viewBox`;
- remain clear at 18 by 18 pixels;
- avoid scripts, animation, embedded raster data, and remote dependencies;
- use paths and shapes rather than depending on an external font; and
- include an SVG `title` and `desc` for direct viewing.

The navigation uses an empty image `alt` because the adjacent repository name
already supplies the accessible link text.
