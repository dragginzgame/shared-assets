# Shared assets

Shared visual assets used across repositories owned by
[`dragginzgame`](https://github.com/dragginzgame).

## Helper icons

Repository icons belong in [`helper-icons/`](helper-icons/). Public READMEs can
reference them through URLs such as:

```text
https://raw.githubusercontent.com/dragginzgame/shared-assets/main/helper-icons/ic-memory.svg
```

The canonical helper-repository list is stored in
[`navigation/helpers.json`](navigation/helpers.json). The matching anchor-tag
menu is maintained in [`navigation/menu.html`](navigation/menu.html).

## Usage

Copy the content between the navigation markers in `navigation/menu.html` into
a repository README. Both the icon and repository name are contained in the
same anchor tag and lead to that repository.
